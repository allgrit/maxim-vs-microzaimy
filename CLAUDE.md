# Максим против микрозаймов — заметки для агента

Браузерная игра без сборки: статические файлы, ES-модули, Canvas 2D, Web Audio. Публикуется
на GitHub Pages из корня `main`. Геймдизайн — `docs/GAME_DESIGN.md`, туда же вносить изменения
баланса и новых сущностей.

## Правила проекта

- Чистая логика живёт в `src/core/` и не трогает DOM/Canvas — тесты `npm test` (node --test).
  Новая механика с числами (баланс, перки, волны) — сначала в `core` с тестом, потом в `game.js`.
- Размер арены динамический: `world.W/H/safeTop` из `src/game.js`. Портрет 600×1000 с `safeTop`
  под HUD, ландшафт 1000×640. Координаты никогда не хардкодить под один режим.
- Атмосфера управляется `game.tension()` (0..1): фон, виньетка, вид Максима, музыка, гул,
  сердцебиение. Новые «сгущающие» эффекты вешать на неё, не на отдельные счётчики.
- Реплики и заголовки: базовые списки и «поздние» (абсурд) в `src/core/config.js`; переключение
  по `tension()` и дню — в `Game.quote()` / `Game.headline()`.
- Ассетов нет и не должно быть: всё рисуется кодом, звук синтезируется.
- Отладочный доступ из консоли браузера: `window.__mvm` (game, startRun, world).

## Проверка

- `npm test` — ядро.
- Визуально: Playwright, вьюпорт 390×844 (портрет) и 1280×800. Для скриншота мид-геймплея
  прогнать `game.update()` в цикле через `__mvm.game`, затем `game.phase = 'paused'`, иначе
  цикл кадров уведёт состояние.
