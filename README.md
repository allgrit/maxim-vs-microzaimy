# Максим против микрозаймов

Сатирическая аркада-выживалка на злобу дня. На Максима оформили микрозайм без его ведома, и теперь
весь мир микрофинансов пытается оформить его ещё раз. Договоры летят в лицо, промоутеры суют
листовки, коллекторы тянут цепями, роботы-автодозвоны звонят без остановки. Уклоняйся, рви бумаги,
закрывай поп-апы и доживи до заявления в полицию.

**Играть:** https://allgrit.github.io/maxim-vs-microzaimy/

Работает в браузере на телефоне и компьютере, без установки. Всё — графика, звук, музыка —
рисуется и синтезируется кодом, ассетов нет.

## Что внутри

- 10 видов «механик ловли»: договор, промоутер с листовками, звонок с кольцом, СМС-спам, ловушка
  «Подпишите здесь», поп-ап, коллектор с цепью, автодозвон, мимик «Мы из банка», дрон-курьер.
- 5 боссов каждые 5 дней, у каждого две фазы. Во второй фазе босс «повышается» — титул растёт
  абсурдно, реплики теряют связь с реальностью.
- Две шкалы поражения: нервы и долг. Долг капает процентами сам.
- Роглайт: 16 перков в забеге (обычные и редкие), мета-магазин «Юридическая консультация»,
  стили Максима, достижения.
- Миссии в забеге, серии разрывов с множителем до ×5, модификаторы дня, газетные заголовки.
- Атмосфера сгущается по мере роста долга: цвета, музыка, гул, сердцебиение, вид Максима.
- Лидерборд по сложностям и ежедневный вызов с общим сидом. Результат копируется текстом.
- Три сложности, бесконечный режим после победы.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | WASD / стрелки | джойстик: коснись экрана и веди |
| Рывок | Shift | кнопка «Рывок» |
| «Отказ!» | Пробел / клик | кнопка «Отказ!» |
| Заявление в полицию | E | кнопка «Полиция» |
| Пауза | Esc | кнопка II |
| Звук | M | в меню |

## Разработка

Статический сайт без сборки: `index.html`, `styles.css`, ES-модули в `src/`.

```
npm test          # тесты чистой логики (node --test)
npm run serve     # локальный сервер на :8080
```

- `src/core/` — чистая логика без DOM: RNG, волны, перки, очки, миссии, сохранение. Покрыта тестами.
- `src/game.js` — состояние забега, сущности, боссы, коллизии.
- `src/render.js` — отрисовка на Canvas.
- `src/audio.js` — синтез звука и музыки через Web Audio.
- `src/main.js` — экраны, HUD, цикл.
- `docs/GAME_DESIGN.md` — геймдизайн-документ.

Деплой: push в `main` → GitHub Pages из корня репозитория.
